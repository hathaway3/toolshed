# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest release | :white_check_mark: |
| `main` branch  | :white_check_mark: |

## Reporting a Vulnerability

ToolShed is a public domain suite of retro-computing cross-development tools that manipulate offline disk images and firmware binaries. There is no network service, authentication, or sensitive data handling. If you discover a bug with security implications (e.g., a buffer overflow when parsing a malformed disk image), please report it via a standard [GitHub Issue](https://github.com/nitros9/toolshed/issues/new?template=bug_report.yml). Given the offline, non-privileged nature of these tools, there is no need for a private reporting channel.
